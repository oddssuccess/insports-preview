選單說明

選單說明
Dashboard後台總覽，顯示產線摘要與待處理事項的捷徑。
Users & Permissions後台使用者、角色與權限管理。
Distributors經銷商（Distributor）及其設定管理。
Catalog › Sports運動項目目錄。
Catalog › Tournaments競賽（Tournament）目錄。
Catalog › Competitors參賽方（Competitor）目錄，含隊伍與選手。
Catalog › Market Types玩法（Market Type）目錄。
Catalog › Currencies幣別目錄。
Matches › Schedule統一的單場比賽賽程；點選單場開啟比賽明細（Data Sources 的 States／Properties），列尾選單開啟賽事對應元件，唯讀查看本場與已對應來源。
Matches › Schedule › Match Mapping賽事對應（Mapping）的唯讀視窗，並列統一賽事與已對應來源的識別、競賽及隊伍名稱、對應紀錄（By）與時間；從賽程列尾選單或明細開啟，不另設主選單。
Matches › Odds單場比賽的賠率與操盤（Trading）。
Matches › Results單場比賽的賽果。
Matches › Grades單場比賽盤口與投注項的結算結果（Grade）。
Matches › Issues賽事問題：待取消、待腰斬與狀態未確認的單場比賽，比對來源證據與候選後裁定，需要時另一人覆核。
Outrights › Schedule統一的冠軍盤（Outright）賽程；點選事件開啟冠軍盤明細，查看事件資料、投注項與變更紀錄。
Outrights › Schedule › Outright Detail冠軍盤明細，從單一事件開啟，並提供已對應來源視窗入口，不另設主選單。
Outrights › Schedule › Outright Mapping冠軍盤對應元件，唯讀並列各來源與事件、投注項的識別配對，不另設主選單。
Outrights › Odds冠軍盤的賠率與操盤。
Outrights › Results冠軍盤的賽果。
Outrights › Grades冠軍盤投注項的結算結果。
Provider › Tournaments來源競賽：依來源（Provider）及運動查看識別、原始名稱、相關賽事與既有統一紀錄。
Provider › Competitors來源參賽方：依來源及運動查看識別、原始名稱、相關賽事與既有統一紀錄。
Provider › Matches › Schedules來源單場賽程：來源提供的單場比賽賽程，唯讀。
Provider › Matches › Odds來源提供的單場比賽賠率。
Provider › Matches › Results來源提供的單場比賽賽果。
Provider › Outrights › Schedule來源冠軍盤賽程：來源提供的冠軍盤賽程；點選事件查看來源的投注項清單與變更紀錄，唯讀。
Provider › Outrights › Odds來源提供的冠軍盤賠率。
Provider › Outrights › Results來源提供的冠軍盤賽果。
Settings › Market Type Settings › Matches單場比賽的玩法設定。
Settings › Market Type Settings › Outrights冠軍盤的玩法設定。
Settings › Provider Settings資料使用、連接器、運動與玩法收集、賽程來源及名稱分類規則。
Content › Announcement公告管理。
Content › Game Rules玩法規則說明內容。
Ticket Operations › Ticket List注單（Ticket）清單與狀態查詢。
Ticket Operations › Ticket Confirmation等待確認的注單，人工接受或拒絕。
Risk Management風控（Risk Management）監控、警示與規則。
Reports投注額、GGR 等營運報表。
