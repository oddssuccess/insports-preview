後台畫面示意（wireframe）

狀態：草稿（示意） · 說明：wireframe README · PRD：PRD 目錄

後台各頁面的畫面示意，與 PRD 第 8 節「參考設計（非約束）」同一定位：只說明畫面要提供哪些資訊與操作，不約束版面、元件或資料模型。頁面依後台主選單排列，每頁開頭列出功能清單與對應的 PRD 規則，末尾列出待確認事項與關鍵字中英對照。畫面中的名稱與數字都是範例；畫面上的文字一律使用英文，說明文字使用中文。PRD 放在 GitHub 上，需要 repo 的存取權限才能開啟。

共用版面

後台共用版面（已採用選單與完整流程規劃）：第一階段包含單場比賽與冠軍盤的建立、賽程、識別、屬性、生命週期、對應及人工審核；詳細賽況、賠率與賽果／結算列為後續。可切換 BetLogics 導覽對照與完整流程規劃；未繪製的入口標示 Planned，Feed Monitor 保留既有位置、階段歸屬待定。

Catalog

運動（Sports）清單、變更營運狀態、營運狀態變更紀錄、多語系、排序看板（PRD 01）
競賽（Tournaments）清單與下一場賽事、編輯屬性與圖示、等級看板、多語系、排序看板（PRD 01）
參賽方（Competitors）清單與下一場賽事、依競賽篩選、編輯類型、屬性與圖示、等級看板、多語系、排序看板（PRD 01）
玩法（Markets）依運動的玩法清單與預覽、冠軍盤玩法、玩法類型（投注規則）清單與明細、玩法對應表、未對應的玩法、多語系（PRD 01、03、04、05）

Matches

單場比賽賽程（Schedule）參考 BetLogics 的分組賽程與單場導覽、身分與目錄屬性、來源與生命週期、待審摘要與人工紀錄；含 PRD 規則分工與待確認事項（PRD 01、03、04、11）
賽事對應（Mapping）候選比較、人工確認、對應更正、新競賽與參賽方處理（PRD 01、03、04、11）
賽事審核（Match Review）待取消／待腰斬佇列、來源回歸、重掛、生命週期裁定與覆核（PRD 04、07、11）

Outrights

冠軍盤賽程（Schedule）事件身分、期間、名單、來源證據與生命週期缺口（PRD 01、03、04、11）
冠軍盤對應（Mapping）事件候選、名單逐項對應／排除、鎖定與人工紀錄（PRD 01、04、11）

Provider

來源單場賽程（Matches › Schedule）來源場次、取得狀態與時間、候選阻擋、人工指定建立者（PRD 01、03、04、11）
來源冠軍盤賽程（Outrights › Schedule）來源事件、期間與名單、對應進度、來源狀態與未定建立流程（PRD 01、03、04、11）
