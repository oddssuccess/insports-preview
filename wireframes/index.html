後台畫面示意（wireframe）

說明：畫面使用說明 · PRD：PRD 目錄 · 共用版面：layout

階段內容

Phase 1: SCHEDULE

目標：能由來源資料建立 InSports 統一賽事，並正確匯入賽事狀態與屬性。 · 期限：11 月 10 日

頁面異動畫面元件
Catalog › SportsNew運動清單、編輯視窗（狀態、多語系）、排序
Catalog › TournamentsNew競賽清單、編輯視窗（基本資料、狀態、多語系）、等級看板、排序
Catalog › CompetitorsNew參賽方清單與競賽篩選、編輯視窗（基本資料、多語系）、等級看板、排序
Catalog › MarketsNew依運動的玩法清單與明細、冠軍盤玩法、多語系視窗
Matches › ScheduleNew狀態頁籤、競賽分組與收合、比分與時段、競賽篩選、賽事對應入口
Matches › Match DetailNewStates（各來源回報時間差）、Properties（開賽時間與傷停補時變更紀錄）、Match Mapping 視窗
Matches › IssuesNew問題佇列、待取消／待腰斬／狀態未確認案件、來源證據、裁定與覆核
Outrights › ScheduleNew事件、玩法、開始日期、統一狀態與設定模板
Outrights › Outright DetailNew事件資料、投注項清單、變更紀錄、Outright Mapping 視窗
Provider › TournamentsNew依來源與運動檢索、競賽明細、無搜尋結果
Provider › CompetitorsNew依來源與運動檢索、參賽方明細、無搜尋結果
Provider › Matches › SchedulesNew來源場次清單、賽前頁籤與競賽收合、選擇競賽
Provider › Outrights › ScheduleNew來源冠軍盤清單、來源明細（投注項與連結狀態）、變更紀錄
Settings › Provider SettingsNew五個頁籤：資料使用（開關與狀態）、連接器（暫停、恢復與啟用）、運動與玩法收集、賽程來源、名稱分類規則

頁面導覽

依後台主選單排列；縮排表示子頁（Subpage）與視窗（Pop-up）。尚未畫出的選單項目不列入。

Catalog
  • Sports清單與排序
    • Edit SportPop-up營運狀態與變更紀錄
    • Edit Sport · TranslationsPop-up多語系
  • Tournaments清單、等級看板與排序
    • Edit TournamentPop-up基本資料、停用與恢復
    • Edit Tournament · TranslationsPop-up多語系
  • Competitors清單、依競賽篩選、等級看板與排序
    • Edit CompetitorPop-up基本資料
    • Edit Competitor · TranslationsPop-up多語系
  • Markets依運動的玩法清單與明細、冠軍盤玩法
    • Edit Market · TranslationsPop-up多語系
Matches
  • Schedule依狀態頁籤與競賽分組的單場清單、競賽篩選
    • Match DetailSubpageStates 與 Properties 的逐項變更紀錄
      • Match MappingPop-up已對應來源的識別、名稱與對應紀錄
  • Issues待取消、待腰斬與狀態未確認的問題佇列、裁定與覆核
Outrights
  • Schedule事件、玩法、開始日期、統一狀態與設定模板
    • Outright DetailSubpage事件資料、投注項清單與變更紀錄
      • Outright MappingPop-up各來源與事件、投注項的識別配對
Provider
  • Tournaments依來源與運動檢索競賽
  • Competitors依來源與運動檢索參賽方
Matches
  • Schedules來源場次、狀態頁籤、比分與文字轉播、競賽篩選
Outrights
  • Schedule來源冠軍盤、開始日期、狀態、已連結的統一冠軍盤、投注項與變更紀錄
Settings
  • Provider Settings資料使用、連接器、運動與玩法收集、賽程來源、名稱分類規則
    • Data UsageTab各來源的資料使用開關、各類資料狀態與賽程來源保護
    • ConnectorsTab連接器與來源的關係、暫停、恢復與啟用、影響提醒及變更紀錄
    • Sports & MarketsTab依來源開關連接器收集的運動與玩法
    • Fixture SourcesTab各運動的賽程來源、頁內更換與儲存
    • ClassificationTab競賽與參賽方屬性、電子競技遊戲歸屬的名稱分類規則（新增、編輯、刪除與啟停）
