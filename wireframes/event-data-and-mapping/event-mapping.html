  5. 5主隊在上、客隊在下，一律顯示來源自己的寫法，不顯示統一名稱，提醒名稱相似不是依據（R04-08）。右側徽章：已對應時顯示該統一賽事目前有幾個來源（含建立者）；未對應時顯示首次出現至今的時間。
  6. 6最後一欄只有兩種記號：✓ N 是這個來源賽事與其他來源之間已確認的對應數；候選 N 是尚未確認的候選數（兩個方向都說得通、多個候選都符合等，系統不猜，R04-09）。依據、方向與等待原因在右側面板與對應明細，不在列上。
